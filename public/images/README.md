# Invitation image assets

- `cinematic-church-hero.webp` — wide cinematic cover image for desktop and larger screens.
- `cinematic-church-hero-mobile.webp` — center-cropped portrait version for narrow viewports.
- `ivory-blush-rose-spray.webp` — transparent floral overlay used as a reusable decorative accent.
- `couple-wedding-3d.webp` — cinematic 3D-style edit based on the full-length couple photo.
- `couple-candid-3d.webp` — matching edit based on the candid couple photo.
- `IMG_2012(1).jpeg` and `IMG_1741.jpeg` — supplied originals used by the photo toggle and gallery.
- `../og-wedding.jpg` — 1200 × 630 social-sharing preview image.
- Symbolic SVG gallery art from the supplied design ZIP is stored in `public/assets/`.

The church and floral artwork are generated decorative assets and do not claim to show the actual ceremony venue. Original portrait files are preserved outside `public/` at `assets/source-photos/`.
