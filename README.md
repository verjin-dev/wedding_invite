# Verjin & Jesmi — Wedding E-Invitation

React 19 + Vite 6 + TypeScript + Framer Motion + Lucide. Mobile-first blue-watercolor invitation with an envelope opening, countdown (IST), events, gallery with lightbox, RSVP and share.

## Run

```bash
npm install
npm run dev      # local dev
npm run build    # typecheck + production build into dist/
npm run preview  # serve the build
```

## Edit content

Everything lives in `src/data/wedding.ts`: names, date, verse, message, venues, map links, story text, gallery.
Map links are Google Maps *search* URLs (no invented coordinates) — swap in exact place links when confirmed.

## RSVP

`wedding.rsvp` has `whatsappNumber` (digits with country code, e.g. `919876543210`) and `email`. While both are empty the form is disabled and labelled "not enabled yet". When set, submitting opens WhatsApp / the mail app with the message prefilled. No backend exists, so responses are **not stored** — they only arrive when the guest presses send.

## Assets

- `public/florals/*.svg` — generated by `node scripts/make-florals.mjs` (corner hydrangea spray used top-left and rotated bottom-right, accent spray, divider, emblem, paper texture). These are stylised SVG stand-ins; replace with commissioned watercolor PNG/WebP if desired, keeping filenames.
- `public/images/IMG_2012(1).jpeg`, `IMG_1741.jpeg` — original couple photos (used in couple, story, gallery).
- `public/images/*-3d.webp`, `cinematic-church-hero*.webp`, `ivory-blush-rose-spray.webp` — stylised/illustrative renders from earlier work; alt text says they are illustrative. The church image is not the real venue.
- `public/og-wedding.jpg` — social preview (still the earlier candlelit-church image; replace with a blue-watercolor card for a matching WhatsApp preview).
- Not yet provided: real church/hall photos, rings and bouquet photos, separate groom/bride portraits (source files are in `assets/source-photos/`; optimise to WebP before using).

## Deploy

Static site: build with `npm run build` and publish `dist/` on Netlify, Vercel, GitHub Pages or Cloudflare Pages (build command `npm run build`, output `dist`). For WhatsApp previews, set absolute `og:image`/`og:url` in `index.html` to the deployed domain.
